# The variants of the spec's commented ✗ lines (item SPEC-no-verbatim). Each entry names a fence
# of DESIGN.md or EXAMPLES.md by its key and the lines it changes by a short piece of each; the
# tests build each variant from the spec at test time (tests/src/fences.rs, `build`), so this
# repository keeps no copy of a fence. The words:
#   variant: NAME      starts an entry
#   fence: KEY         the fence, as `DESIGN.md [sec:name] N`
#   live: TEXT         the commented ✗ line made live
#   omit: TEXT         a line left out
#   keep: TEXT         a line kept; an entry that keeps any line leaves out the rest
#   edit: OLD => NEW   OLD replaced by NEW in the line that holds OLD
#   stands: OLD => NEW the live line stands for this edit of another line, which gets its
#                      `// ✗` comment; the commented line stays
# Each TEXT must be held by exactly one line of the fence (for `live:`, one commented ✗ line).
