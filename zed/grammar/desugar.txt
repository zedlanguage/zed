Pin           : the BLAKE3-256 content address the imported unit must have (step M0.7)
Struct        : a record type, and its constructor λ(f1, …). {#f1 -> f1, …}, a family keyed by field atoms; the grammar form also derives the struct's parser and printer (sec:tour_grammar)

Field         : a field name and type; `import P` copies the fields of P, a field it brings in twice counting once when the two are equal (sec:introspection)

Law           : the obligation ∀ params. ⟦e⟧, discharged by the ladder or by its proof (sec:verification); no run-time term
Function      : binds the name to λ(params). ⟦Body⟧; a function whose body reads its own name, or a name of its recursive group, is the definedness fix over its parameter domain, evaluated on demand (L6)

PosParam      : a positional parameter
TupleParam    : `(a, b)` is a fresh parameter p with `let a = p[0]`, `let b = p[1]` in the body
PositionalParam : a parameter passed by position, its default filled at saturated calls that omit it
Param         : a named parameter, its default filled at saturated calls that omit it
Result        : the output of a function
Ports         : declares output ports, each written by push
ResultType    : declares the result type
Port          : an output port's name and type
Body          : the λ body ⟦e⟧ or ⟦Block⟧; trailers add no term
Trailer       : the trailer of its alternative
TestTable     : a list of test cases
TestCase      : `a -> b` asserts ⟦f(a)⟧ == ⟦b⟧ for the enclosing f, run by `zed test` (step L1.21); for `main`, that a wave reading the ports ⟦a⟧ writes the bytes ⟦b⟧
Proof         : a derivation checked by the proof checker (sec:verification); no run-time term
IndexedDef    : `f[i in D] = e` is fam(⟦D⟧, i -> ⟦e⟧) when e does not read f, the definedness fix(⟦D⟧, step, ev) with `this` = f when it does, and gen when the reads are one step back in a time order (sec:generations); several `[ ]` nest; the boundary's entries are defined before the first round
IndexKey      : `i in D` binds i over the keys of ⟦D⟧; an expression is the key of one case of a piecewise definition
Push          : a push
KeyedPush     : writes ⟦e⟧ at keypath ⟦k⟧ of a keyed accumulator, whose writes at one keypath are folded by its reducer
WholePush     : push(p, ⟦e⟧)
Binding       : the binding of its alternative
TypedBinding  : `x: T = e` is PlainBinding's `x = e`, also checking e against T
PlainBinding  : `x = e;` is let x = ⟦e⟧ over the block, in dependency order; `a, b = e` is let t = ⟦e⟧ with a = t[0], b = t[1], and `_` binds nothing; a boundary gives the entries before generation 0
Target        : a bound name, or `_`, which binds nothing
Boundary      : the entries a generation variable or indexed definition holds before its first step or round: the init of its gen, or entries defined before a fix's first round
BoundaryItem  : one boundary entry, `x[-1] = e`
Signature     : the type of a name with no definition, a foreign function (sec:ffi) or a declared accumulator; no term
Expr          : ⟦Lambda⟧, ⟦Break⟧ or ⟦Expr12⟧
Break         : ends the enclosing gen: the step's guard returns #break(⟦e⟧) and the loop's result is ⟦e⟧
Lambda        : λ(params). ⟦body⟧, each parameter's kind taken from the expected function type (sec:power)
Expr12        : `a else b else c` is (a else b) else c: each else tail applies to the expression before it, left to right
ElseTail      : `e else d` is match ⟦e⟧ { a -> ⟦d⟧ for each loose atom member a of e's type, x -> x }; `e else P -> d` is match ⟦e⟧ { P -> ⟦d⟧, x -> x }
Or            : `a || b` is if(⟦a⟧, true, ⟦b⟧), left to right
And           : `a && b` is if(⟦a⟧, ⟦b⟧, false), left to right
Equality      : `a == b` and `a != b` are the primitives eq and ne
EqChain       : `a == b == c` is let t = ⟦b⟧ in (⟦a⟧ == t) && (t == ⟦c⟧), and in a proof the #chain derivation of its links
Relation      : the comparison of its alternative
AscChain      : a chain of `<` and `<=`, as in EqChain
DescChain     : a chain of `>` and `>=`, as in EqChain
Compare       : the primitives lt, le, gt and ge
IsTest        : the type test of ⟦e⟧ against T, a bool
InTest        : `e in D` is match get(⟦D⟧, ⟦e⟧) { #notFound -> false, _ -> true }, and `not in` its negation
Reduce        : the tails applied left to right to ⟦Range⟧
ReduceTail    : `F >< op` is fold(⟦F⟧, ⟦op⟧, ev) with the evidence the checker attaches (sec:reduction); `as (p)` names the levels of ⟦F⟧ and `into (q)` is the reindex its output pattern builds, with a fold for each level collapsed by `><` (sec:remap_law); `with { u, … }` is discard(⟦F⟧, keep all but the updated keypaths) ⊎ the updated entries; `with f(…)` attaches a facet (sec:facets), adding its failure members and leaving the term unchanged
Unordered     : the fold's evidence permits any grouping and order (sec:reduction)
Range         : `a ..< b`, `a ..= b` and `a ..` are the domains {a, …, b−1}, {a, …, b} and {a, a+1, …}, built by the primitive range; an unbounded domain is read only by generators that stop
RangeTail     : the upper end of a range, exclusive, inclusive or absent
Additive      : the primitives add and sub; `++` on String and on rank keys is the offset concatenation, the right operand reindexed by rank + count(⟦a⟧) unioned with ⟦a⟧; on Seq (L5) it is the union of the operands, which keep their origin keys, the right operand ordered after the left (sec:order), and operands whose keys overlap are a collision
Multiplicative: the primitives mul, div, intDiv and mod
Prefix        : the primitives neg and not
Power         : the primitive pow, right-associative
Postfix       : the suffixes applied left to right to ⟦Primary⟧
Suffix        : the suffix of its alternative, over its receiver x
CallSuffix    : the application with its arguments in parameter order, defaults filled and `...` a λ over the parameters left out
IndexSuffix   : get on a family, application on a function, tupleGet on a tuple
MemberSuffix  : get(x, #n) where x's type guarantees the field n, else the application n(x, …)
SafeSuffix    : match ⟦x⟧ { a -> a for each atom member a, v -> ⟦v.n⟧ }
SpreadSuffix  : the method call that writes the receiver's next generation
ReadSuffix    : a compile-time read replaced by the value it denotes, except the run-time reads (sec:property_tracking)
Update        : one keypath and its new value in a `with { }` update

FacetCall     : a facet record name(args), its arguments compile-time-stage
Args          : the arguments, resolved by the call rules (sec:power) to positional kernel arguments
NamedArg      : the argument of the named parameter; `name:` alone is `name: name`
PosArg        : the positional argument of its alternative
SortArg       : a sort key
PlainArg      : a positional argument
Primary       : the primary of its alternative
AtomExpr      : a literal term

TupleExpr     : the primitive tuple

Literal       : the literal value; a float literal rounds once to the nearest double
BinOp         : the operator's primitive as a function; `&&` and `||` are λ(a, b). ⟦a && b⟧ and λ(a, b). ⟦a || b⟧
Block         : its bindings as lets in dependency order (statement order has no meaning), over the final expression or the return tuple
Display       : `{ n: e, … }` is the record {#n -> ⟦e⟧, …}, `n:` alone is `n: n`; `{}` the empty family; `{ k -> v, … }` the family of those entries, a repeated key being a collision; `{ k, … }` the set of those keys
Entry         : one entry of a display
If            : if(⟦c⟧, ⟦a⟧, ⟦b⟧)
Match         : match ⟦e⟧ { ⟦arm⟧, … }, first arm first, exhaustiveness checked by the elaborator
Arm           : `p -> e` is the kernel arm; `p where g -> e` is `p -> if(⟦g⟧, ⟦e⟧, r(x))` with r the match of the remaining arms as a λ applied to the scrutinee x; a pattern the kernel lacks is a Bind with that guard
For           : fam(⟦D⟧, k -> ⟦body⟧) over the generator's levels, with `where g` a discard of the entries where g is false and an emission level for a body with emits; several generators nest left to right (L5)
MoreGen       : an inner generator, nested in the previous one
Generator     : binds the InPattern to the levels of ⟦D⟧: `k in D` its keys, `k -> v in D` its keys with v = get(⟦D⟧, k), deeper levels nested
Loop          : gen(init, step, guard): init the frame of the generation variables' boundaries, step the λ from a frame to the frame of primed values, the guard from `while`, `until` and `break`; a loop of monotone inflationary steps on a lattice of finite height is the lattice fix (sec:generations)
